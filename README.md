# SmartSoft Labs — Futuristic Digital Lab

A responsive React + Vite agency website starter using Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Before publishing

1. Replace `hello@smartsoftlabs.org` in `src/App.jsx` with the agency's verified email address.
2. Update project data in the `projects` array with verified project names, descriptions, screenshots, and live URLs.
3. Replace conceptual project UI mockups with screenshots or video previews of actual projects.
4. Verify all company details, services, client testimonials, metrics, phone numbers, and other claims before publishing.
5. Add a real form backend or form service if you want messages submitted without opening the visitor's email app.
6. Add the agency's verified social links and privacy policy if needed.

The portfolio cards currently use conceptual UI mockups and intentionally have no live demo links until real URLs are added.
